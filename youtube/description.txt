An agentic homebrew Pac-Man conversion for the Commodore VIC-20: coding agents carried out the porting, 6502 implementation, debugging and testing, guided by my requirements and live play testing.

This is the INITIAL PASS, recorded before the later glyph-pool renderer and optimization series. It already preserves the arcade maze, ghost behavior, scoring, sound sequencing and intermissions, but the software sprites visibly flicker.

The computer-controlled playthrough clears the first two boards and completes the first intermission. A joystick bot supplies ordinary inputs in VICE; movement, collisions, scoring and progression are handled by the game. The bot recording the video is separate from the coding agents that helped build the conversion. There is no spoken commentary.

HOW IT WAS BUILT
The conversion builds on Mark Burkley's C translation of the original arcade program, compiled to native 6502 code with LLVM-MOS, plus handwritten assembly. Coding agents adapted the platform code, character graphics, sound driver and validation tools. I directed the work, reviewed experiments and decided what to keep.

The VIC-20 has no hardware sprites. Moving actors are drawn into programmable character graphics. White maze walls and pellets help manage the shared foreground color in each 8x16 cell; colored actors can still tint neighboring pixels. Maze completion flashes blue and white.

AFTER THIS INITIAL PASS
Later work introduced a finished-cell glyph pool to greatly reduce the visible erase/redraw flicker, revised the character artwork and lettering, and optimized rendering, ghost processing and audio. Those changes belong to the separate Final Optimized milestone, not this recording.

TECHNICAL NOTES
Target: expanded NTSC VIC-20, with +3K and BLK1/2/3/5 RAM enabled.
Capture: VICE, joystick input only; both boards reach 244 eaten pellets through gameplay.
This recording includes one lost life and a brief look at board 3 after the intermission.
Gameplay uses its approximately 60.606 Hz logic clock; display redraws are separate.
